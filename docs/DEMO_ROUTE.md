# Маршрут проверки демо — Prompt Review

Как быстро убедиться, что аудит промптов работает: вставить свой
промпт и проследить путь от оценки до улучшенной редакции.

## Маршрут проверки

1. **Открыть** [Live demo](https://prompt-review-demo.alex-n8n.site) →
   **вставить** свой промпт в веб-форму → **дождаться** результата
   (замер: 3–11 с).
2. **Прочитать** анализ → **увидеть** оценку по 8 инженерным критериям
   (0–10: ясность, полнота, однозначность и другие), сильные и слабые
   стороны и приоритет исправлений — конкретные слабые места, не средний
   балл.
3. **Сравнить** с каноническим примером из документации, например для
   критерия «Ясность»:
   - ❌ «Напиши что-нибудь про Python»
   - ✅ «Напиши обзорную статью о применении Python в data science
     для начинающих»
   → **получить** улучшенную редакцию своего промпта в том же формате.
4. **Проверить** различение: отправить обычный текст (не промпт) →
   **увидеть**, что сервис отделяет промпт от обычного текста и
   обрабатывает их по-разному.

## Что ещё доступно

- Три канала с одним контрактом ответа: Web UI, Telegram-бот
  ([@OptimusPromptReview_bot](https://t.me/OptimusPromptReview_bot)),
  REST API (`POST /review`) — на API можно строить автоматический аудит
  промптов, например в CI.
- Ограничения публичной демо-версии: счётчик запросов и таймер сессии
  в шапке, новая сессия в один клик (см.
  [SYSTEM_DEMO.md](https://github.com/AlexLvGulyaev/PromptReview/blob/main/docs/SYSTEM_DEMO.md)).
- Разбор всех 8 критериев с примерами:
  [USER_GUIDE.md](https://github.com/AlexLvGulyaev/PromptReview/blob/main/docs/USER_GUIDE.md).
